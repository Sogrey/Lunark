# 冒烟与压测清单（非功能）

主路径：**Tauri**（`pnpm tauri:dev`）。浏览器（`pnpm dev`）仅作快捷键/UI 回归；无原生菜单与部分文件系统能力。

对照表：`src/lib/help/content.ts` → `SHORTCUT_ROWS`。

---

## 1. 浏览器快捷键回归（Toolbar 已删）

前置：`pnpm dev`，焦点在编辑区。

| 键 | 期望 |
|---|---|
| Ctrl+O / Shift+O / N / S / Shift+S | 打开 / 文件夹 / 新建 / 保存 / 另存为（浏览器下对话框能力有限则至少不抛错） |
| Ctrl+W | 关标签（脏文档提示） |
| Ctrl+/ | 混合 → 源码 → 双栏 |
| Ctrl+\ | 侧栏显隐 |
| Ctrl+F / H | 查找 / 替换（混合下 F 会切源码并提示） |
| Ctrl+Shift+F | 侧栏「搜索」 |
| Ctrl+Tab / Shift+Tab | 下一 / 上一标签 |
| F1 | 快捷键说明对话框 |
| F8 / F9 | 专注 / 打字机 |
| Esc | 关查找；再 Esc 退专注 |

桌面端：快捷键由**前端统一绑定**（Windows/WebView2 下菜单 accelerator 常不可靠）；菜单旁仍显示加速键文案，点击菜单与按键经防双触发合并。菜单 **帮助 → 快捷键说明 / 关于**。标签栏 **+** / 双击空白 = 新建。

---

## 2. 旧 prefs 升级启动

prefs 文件：`lunark-prefs.json`（plugin-store）。

1. 写入残缺 / 脏数据后冷启动，例如仅 `{ "viewMode": "wysiwyg", "foo": 1, "splitRatio": 9 }`。
2. 期望：启动不白屏；`viewMode` 回落 `hybrid`；`splitRatio` 夹到 [0.2, 0.8]；未知键不进入后续 save 白名单。
3. 正常改主题 / 侧栏后重启，字段仍在；`themeId` 非法则回默认。

实现：`src/lib/prefs/store.ts` → `loadPrefs` 白名单回填。

## 3. 大文档 / Crepe 性能（人工压测）

准备：≥ 2000 行 md（多标题、代码块、2+ 表格、若干 Mermaid）。

| 场景 | 关注 |
|---|---|
| 混合模式打开 | 首屏可交互时间；是否长时间空白 |
| 连续输入 | 卡顿 / 输入延迟 |
| 混合 ↔ 源码 ↔ 双栏 | 切换耗时、内容是否丢失 |
| 大纲跳转 | `jumpToLine` 是否等 CM 就绪 |
| 双栏滚动 + 预览 | 预览防抖是否跟上；主题切换后代码块是否重渲 |
| 导出 PDF/HTML | 大文档是否可完成（可接受慢） |

记录：机器、文档规模、体感（可接受 / 卡 / 失败）。未系统自动化前以此清单为准。

---

## 4. 表格定位 / Shiki 主题（债项验收）

- **多表格**：混合模式文档内 ≥2 张表；对第二张改列对齐 / 增删行列，源码应对准该表。
- **Shiki**：亮色主题（如 Whitey）下预览代码为浅底；切 Night 后为深底；Mermaid 同步刷新。

---

## 5. 混合局部语法糖（手测）

前置：视图 = **混合**。

| 操作 | 期望 |
|---|---|
| 粗体/斜体/行内代码/链接，光标移入 | 露出 `**` / `*` / `` ` `` / `[…](…)` |
| 光标离开 mark | 分隔符消失 |
| 空标题 | 始终显示 `#`；占位「开始写作…」不叠字 |
| 单击图片 | 上方出现可编辑 `![]()`，改完图更新 |
| 单击行内 `$…$` / 块公式 / Mermaid | 上方源码条；未选中时预览为主、无弹窗抢焦点 |
| 表格内操作 | 不出现源码糖；浮动条仍可用 |
